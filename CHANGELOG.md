# Changelog

## 0.1.0 (2026-10-12)

First release.

- Activities for every configured remote with live state; start, control and turn off.
- Control pad that follows each activity's button mapping, with hold-to-repeat and keyboard shortcuts.
- Live connection, battery, power supply, power mode and device status.
- PIN sign-in with throttling, 30-day sessions and sign-out.
- Nine themes: Miyara, Original, Obsidian & Copper, Roon Dark, Roon Light, Dark Orange, Graphite & Brass,
  Brookwood and Brookwood Light.
- Docker image, Unraid template and an API key script.
